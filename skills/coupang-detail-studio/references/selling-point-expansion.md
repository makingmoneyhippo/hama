# Selling-point expansion

The reference may make an ordinary product feel substantial by changing the buyer's question, the evidence type, and the scene, rather than repeating adjectives. Build an **expansion matrix** for each promising benefit:

| Lens | What the scene must add |
|---|---|
| Friction | What small annoyance or risk does the buyer recognize? |
| Mechanism | Which visible part or action explains how the product helps? |
| Scale | How large, small, light, or easy to handle is it, with a truthful reference? |
| Scenario | In which distinct real-life contexts does this benefit matter? |
| Sequence | Does the action need before/during/after frames or motion? |
| Comparison | What fair, evidenced alternative clarifies the benefit? |
| Objection | What concern does the claim raise, and what can answer it? |
| Proof | Which real image, demonstration, specification, or test supports it? |

Prioritize lenses that change the buying decision. One benefit may deserve ten scenes if each supplies new information; another may need only one. Do not impose equal scene counts. Build variety in composition and rhythm: wide scene, close detail, hand action, diagram, quiet spec panel, real usage, motion, and FAQ where useful. Return to a core benefit later from a different context so the long page has a recognizable thread.

Before adding a scene, ask: “What new customer question does this answer?” If the answer duplicates an earlier section, merge or remove it. An unsupported quantitative claim, invented test, false certification, or generic lifestyle scene does not count as an expansion. Never turn the reference product's fact or asset into a new product fact.

For a tiny metal swivel clasp, a possible *planning* bank is: visible opening tab; a real hand attaching it to a key ring; swivel action shown in a verified sequence; close-up of the joint; fit with a specific strap or ring; several measured sizes; finish options; a real load test if supplied; how to choose the right size; use limitations. Each requires the matching source evidence before it becomes publishable. This is an illustration of breadth, not an assertion about any supplied SKU.
